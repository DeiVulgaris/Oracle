# 🏛️ Oracle: Flip & Resonance (MVP v1.5)

**Oracle: Flip & Resonance** — это минималистичный мобильный психотерапевтический интерфейс, разработанный для преодоления паралича анализа, снятия ментальной фрустрации и ведения персистентного диалога со своим Бессознательным. 

Проект построен на стыке **онтологии процессов (Логоса)**, **теории игр против хаоса** и **биологического резонанса**. Механика взаимодействия полностью имитирует ритуал открытия физической карты из колоды «рубашкой вверх».

---

## 👁️ Онтология и Философия проекта

Современный генеративный ИИ заперт в производстве пустых «оригинальных форм». Данный проект возвращает приоритет **Истинному Различию** — сдвигу в самом контексте восприятия (радость, меланхолия, тоска, страх), а не форме, ее вызывающей. 

Человек здесь выступает как *природный генератор Логосных различий*. Столкнувшись с интеллектуальным или эмоциональным тупиком (deadlock), человеческий мозг испытывает фрустрацию. Через жест переворота смартфона и соприкосновение с неминуемым бинарным выбором Оракула, система совершает **ортогональный смысловой прыжок**, схлопывая проблему и открывая новый контекст реальности.

## ⚙️ Ключевая механика взаимодействия (Три Такта)

1. **Такт 1. Загадывание (Face Down):** Пользователь кладет смартфон на стол **экраном вниз** (`z > 7.5`). Экран полностью гаснет. Система переходит в режим тишины, давая человеку время сформулировать вопрос, и параллельно «запекает» случайный ответ в памяти.
2. **Такт 2. Стабилизация (Пауза):** Пользователь переворачивает телефон **экраном вверх** к себе (`z < -5.0`). Экран остается черным ровно **1.0 секунду**. Это кинематографическое «зависание», фокусирующее внимание и убирающее дребезг датчиков.
3. **Такт 3. Синестетическая вспышка:** По истечении секунды ответ резко вылетает из темноты, **вспухает с 0 до 150% размера** (за 0.15с), упруго **пружинит обратно до эталонных 100%** (за 0.15с) и замирает на **2.0 секунды** для чтения. Одновременно запускается тактильный паттерн вибромотора.
4. **Угасание:** Через 2 секунды статики ответ плавно и медленно **тает на месте в течение 3.0 секунд** (размер шрифта/персонажа не меняется, обнуляется только прозрачность).

## 📳 Синестетическая триада (Смысл — Жест — Тактильность)

Ритм вибрации смартфона идеально синхронизирован с физикой движений персонажа на экране, создавая глубокий синестетический отклик:

*   **🟥 ДА (45% вероятность):** 
    *   *Графика:* Текст «ДА» или персонаж совершает один глубокий, весомый **утвердительный кивок головой сверху вниз**.
    *   *Вибрация:* Монолитный, плотный непрерывный сигнал длительностью **1.0 секунду**.
*   **⬛ НЕТ (45% вероятность):** 
    *   *Графика:* Текст «НЕТ» или персонаж совершает **три резких отрицательных жеста** (качает головой, скрещивает руки или машет пальцем).
    *   *Вибрация:* Три хлестких, синхронных удара, бьющих строго в пики движений: **150мс вибрация / 150мс пауза / 150мс вибрация / 150мс пауза / 150мс вибрация**.
*   **🟦 НЕ ОПРЕДЕЛЕНО (10% вероятность):** 
    *   *Графика:* Персонаж удивленно приподнимает брови и **медленно пожимает плечами с разведением рук**.
    *   *Вибрация:* Тактильный шлейф неопределенности: **150мс (короткий маркер) / 250мс (пауза) / 800мс (мягкая, затухающая вибрация)**.

## 🪙 Модель монетизации (Freemium)

Приложение спроектировано под чистый и честный Freemium-баланс:

### Бесплатно для всех:
*   **Графический режим (Статика):** Строгий монохромный текстовый дизайн (Красный/Серый/Синий) для максимальной тишины и концентрации.
*   **Анимированный режим (Динамика):** Один базовый бесплатный персонаж (минималистичный Призрак или Кот), отрабатывающий все кивки и пожимания плечами.
*   **Вибрационный режим:** Полная поддержка синестетических тактильных паттернов (Морзе-Оракул).

### Премиум-магазин (Кастомизация эстетики):
*   **Пакеты персонажей:** Скелет-философ, Киберпанк-Робот, Готический Алхимик (каждый со своей уникальной мимикой и манерой пожимать плечами).
*   **Инженерное меню физики:** Ручная настройка таймингов (скорость вспухания, время удержания, длительность таяния).
*   **Акустический пак:** Премиальные звуки «выплеска» и вздохи персонажей на непределенности.

## 🚀 Архитектура репозитория и чистый Вайбкодинг

Проект адаптирован под полную изоляцию от локального компьютера разработчика. Вся разработка и сборка происходят в облаке GitHub:

*   **`index.html`** — Веб-версия приложения. Автоматически разворачивается в полноценный тестовый сайт через **GitHub Pages**. Позволяет мгновенно тестировать калибровку датчиков наклона и вибро-паттерны прямо с экрана смартфона.
*   **`main.py`** — Кроссплатформенное ядро на Python (Kivy + Plyer) для мобильного приложения.
*   **`.github/workflows/android.yml`** — Сценарий автоматической облачной сборки. При каждом сохранении (push) кода сервера GitHub Actions в облаке собирают готовый установочный файл **`.apk`** для Android.
