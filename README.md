# 🏛️ Oracle: Flip & Resonance (v2.6 — Freemium SaaS)

**Oracle: Flip & Resonance** — это иммерсивный мобильный психотерапевтический интерфейс, разработанный для преодоления паралича анализа, снятия ментальной фрустрации и ведения персистентного диалога со своим Бессознательным. 

Проект построен на стыке **онтологии процессов (Логоса)**, **теории игр против хаоса**, **кинематографической непрерывности** и **эпистемического нарциссизма**. Механика взаимодействия полностью имитирует ритуал открытия физической карты из колоды «рубашкой вверх».

## 👁️ Онтологические Режимы Информации

Интерфейс разделен на два принципиально разных паттерна восприятия, переключаемых через меню настроек (иконка шестеренки):

### 1. Текстовый Минимализм (По умолчанию / Бесплатно)
Строгий монохромный дизайн для академической тишины и концентрации на чистом смысле. 
* **Физика:** Вспышка Логоса из полной темноты. Ровно через 1.0 сек после переворота экраном вверх текст ответа резко **вспухает с 0 до 150% размера** (за 0.15с), упруго **пружинит обратно до 100%** (за 0.15с), фиксируется на **2.0 секунды** и затем **плавно тает на месте в течение 3.0 секунд** до абсолютной темноты.

### 2. Кинематографическая Непрерывность (Платформа Мульти-Паков)
Экран никогда не гаснет, манифестируя *автономию присутствия*. 
* **Физика:** В покое персонаж находится в бесконечном бесшовном цикле микродвижений (дышит, моргает — `idle.mp4`). При перевороте экраном вниз устройство остается активным, запекая ответ. При повороте к себе, после 1.0 сек стабилизации, персонаж бесшовно переходит в **активный целевой жест** (`yes.mp4`, `no.mp4` или `shrug.mp4`), жестко синхронизированный с синестетической вибрацией. По окончании жеста персонаж **бесшовно возвращается в исходное состояние покоя**, минуя фазы угасания.

## 📳 Синестетическая триада (Смысл — Жест — Тактильность)

Ритм вибрации смартфона жестко синхронизирован с пиками физических движений (текста или тела персонажа):

*   **🟥 ДА (45% вероятность):** 1 длинный, плотный, непрерывный тактильный сигнал длительностью **1.0 секунду** (соответствует утвердительному кивку).
*   **⬛ НЕТ (45% вероятность):** Три хлестких, синхронных отрицательных удара: **150мс вибро / 150мс пауза / 150мс вибро / 150мс пауза / 150мс вибро** (соответствует скрещению рук, знаку «палец вниз» или мотанию головой).
*   **🟦 НЕ ОПРЕДЕЛЕНО (10% вероятность):** Тактильный шлейф неопределенности: **150мс (маркер-вопрос) / 250мс (пауза) / 800мс (уходящее в глубину затухание)** (соответствует архетипическому жесту «весов» — одна ладонь вверх, другая вниз).
